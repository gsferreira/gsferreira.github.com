## _"It worked yesterday. Today it keeps forgetting what I told it."_

You installed Claude Code. You asked it to write a function. It did. So you asked for something bigger, and it rewrote three files you didn't want touched.

Now you're an hour into a session, repeating yourself, wondering if you're holding it wrong.

You are. But not in the way you think.

Claude Code isn't autocomplete with a bigger box. It's a tool with its own rules about context, cost, and control. Once you know those rules, the guessing stops.

## What you'll learn

- How context actually works, and why your session drifts when you ignore it
- How to set up a project so Claude understands it before you type a word
- Development workflows that hold up on real codebases, not toy examples
- Which model to reach for, and what each one costs you
- Git workflows that keep you in control of what lands
- How to customise Claude Code around the way you already work

By the end you'll have a setup on your machine that you can use on Monday.

## What this course is not

It's not a prompt collection you'll stop using in a month. It's not a tour of every flag in the docs. And it's not a pitch that AI writes your code while you watch.

You still do the engineering. This is about the tool getting out of your way.
